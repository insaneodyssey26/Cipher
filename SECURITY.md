# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Cipher is designed with a strict zero-telemetry, offline-first, local-encryption model. If you discover a security vulnerability, sensitive data leakage defect, or cryptographic flaw, please report it responsibly.

### How to Report:
1. **GitHub Advisory (Preferred)**: Navigate to the **Security** tab of this repository and click **"Report a vulnerability"** to submit a private advisory.
2. **Email**: Alternatively, you can email [skmasumali.dev@gmail.com](mailto:skmasumali.dev@gmail.com) with the details and reproduction steps.

Please do **NOT** open public issues or public pull requests for potential security vulnerabilities.

### What to Include:
- A clear description of the vulnerability and its potential security impact.
- Step-by-step instructions or proof-of-concept (PoC) to reproduce the issue.
- Android OS version and device model tested.

You will receive an initial response and acknowledgement within 48 hours.
